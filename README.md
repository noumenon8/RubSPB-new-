# RunSPB

Статический сайт о беге в Санкт-Петербурге.

## Что за что отвечает

- `index.html` - входная страница, перенаправляет на главную.
- `404.html` - fallback для GitHub Pages, перенаправляет на главную.
- `.nojekyll` - отключает обработку Jekyll на GitHub Pages.
- `.github/workflows/pages.yml` - деплой сайта на GitHub Pages.
- `Главная страница/` - главная страница сайта.
- `Маршрут/` - страница маршрутов и фильтров.
- `Мероприятия/` - страница мероприятий и карточек с деталями.
- `Профиль/` - страница профиля и сохраненных данных.
- `Страница входа/` - вход, регистрация и восстановление доступа.
- `fonts/` внутри разделов - локальные шрифты.
- `style.css` внутри разделов - стили конкретной страницы.
- `vars.css` внутри разделов - CSS-переменные страницы.
