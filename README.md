# RunSPB

Статический промо-сайт о беге в Санкт-Петербурге.

## Структура

- `index.html` — входная точка и редирект на главную
- `Главная страница/page1.html` — главная страница
- `Маршрут/index.html` — страница маршрутов
- `Страница входа/page2.html` — страница входа и регистрации

## Локальный запуск

Сборка проекту не нужна. Достаточно открыть `index.html` или поднять статический сервер.

Пример:

```bash
python -m http.server 4173
```

После этого откройте:

```text
http://127.0.0.1:4173/
```

## Публикация на GitHub Pages

Проект уже подготовлен под GitHub Pages:

- есть `.nojekyll`
- добавлен `404.html` с редиректом на главную
- добавлен GitHub Actions workflow для автоматического деплоя

Шаги публикации:

1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. В `Settings` → `Pages` выберите `Source: GitHub Actions`.
4. Сделайте push в ветку `main`.

После этого сайт будет деплоиться автоматически.

## Примечание

В проекте используются папки с кириллическими именами. Для GitHub Pages это допустимо, а ссылки и редиректы уже настроены с учетом URL-кодирования.
